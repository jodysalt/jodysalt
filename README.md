# Jody Salt

I'm a senior full stack software engineer based in Leamington Spa, UK. I build web products end to end: server rendered React front ends, back end services in Node and on the edge, and the tests and pipelines that let them ship safely.

I like pragmatic, well tested, accessible software, and I enjoy working with people who like solving problems as much as I do. I have strong opinions, loosely held.

- **Languages and frameworks:** TypeScript, JavaScript, React, React Router / Remix, Node
- **Infrastructure:** AWS, Cloudflare Workers, Kubernetes, Linux
- **Testing:** Playwright, Cypress, Jest, node:test
- **Front end:** accessible, semantic HTML, CSS, SCSS and Tailwind for desktop and mobile
- **AI assisted development:** Claude Code and agentic tooling

That list is just what I've been using recently. I'm technology agnostic and very comfortable picking up new languages, frameworks and platforms.

## How I think

The best way to see how I approach engineering is my [skills](https://github.com/jodysalt/skills) repo. It's a set of Claude Code skills that run a spec driven workflow. A product vision is broken down into initiatives, tickets and tasks, and then an unattended loop implements, tests and commits each task in turn.

It shows what I value: writing down the intent before writing code, small shippable changes, good guardrails, and automating the repetitive parts of the job.

I use AI a lot these days, but I spent well over fifteen years writing software without it and I'm just as happy working that way. Knowing how to do the work by hand is what lets me judge what the AI produces.
